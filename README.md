# Calculator

A simple browser calculator built with HTML, CSS and JavaScript.

**Live demo:** https://hamzaaitlaadam.github.io/calculator/

## Features

- Addition, subtraction, multiplication and division
- Decimal numbers and backspace
- Chained operations (e.g. `2 + 3 * 4`)
- Friendly message on division by zero
- Keyboard support

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `0`-`9` | Enter digit |
| `+` `-` `*` `/` | Operator |
| `.` | Decimal point |
| `Enter` or `=` | Equals |
| `Backspace` | Delete last digit |
| `Esc` or `Delete` | Clear |

## Files

- `index.html` - page structure
- `style.css` - styling
- `operations.js` - `add`, `subtract`, `multiply`, `divide`, `operate`
- `calculator.js` - display logic, button and keyboard handling
